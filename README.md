# DBASE-Final-Project
Example E-Commerce Database

Steps for set up:

1: Install MySQL

2: Using the MySQL Command Line Client, paste 'source (your file path to the DB)' to initiate the DB

3: (Assuming python is already installed) Open another Command Prompt and paste 'pip install mysql-connector-python'

4: At the top of the Python file, edit the DB_CONFIG section to your MySQL password

5: In the Command Prompt, target the correct file location on your PC, and paste 'py EcommercePY.py' to start the program
